# Maquette mushido.fr v2

Copie statique du site actuel mushido.fr (142 pages) + nouvelle page **Créas UGC & IA**.

- Nouvelle page : `services--creas-ugc-ia.html`
- Accueil : `index.html` (nouveau bloc « Vos créas publicitaires » après « Nos expertises »)
- Entrée « Créas UGC & IA » ajoutée au menu Expertises et au pied de page

## Voir la maquette
1. Bouton vert **Code** puis **Download ZIP**
2. Dézipper, puis ouvrir `index.html` ou `services--creas-ugc-ia.html` dans Chrome

Maquette uniquement : toutes les pages sont en noindex, le site en ligne n'est pas modifié.
Le dossier `original/` contient le HTML d'origine des pages, tel que servi par mushido.fr.
